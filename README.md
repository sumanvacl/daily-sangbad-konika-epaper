# Daily Sangbad Konika — Interactive E-Paper Platform

A legacy PHP-based interactive e-paper application developed for
Daily Sangbad Konika, a Bangladeshi newspaper.

The application connected newspaper page images with individual news
image fragments through XML metadata, allowing readers to select and
open individual news items from a digital newspaper page.

## Project Background

The newspaper's digital publishing workflow involved two separate
platforms:

- The main news portal, operated using WordPress.
- A custom PHP-based e-paper application hosted on a separate
  subdomain and hosting environment.

This repository documents the custom e-paper application, not the
WordPress news portal or the third-party newspaper cutting software.

## My Role and Contributions

I personally designed and developed the PHP-based e-paper application
and integrated the output generated by the newspaper's cutting software.

My responsibilities included:

- Developing the PHP application that displayed newspaper pages.
- Parsing XML metadata using PHP SimpleXML.
- Generating clickable news areas over newspaper page images.
- Connecting clickable areas with individual news image fragments.
- Implementing navigation for multi-fragment news items.
- Developing the PHP workflow that generated title metadata from XML.
- Supporting publication-date-based newspaper editions and archives.
- Handling technical administration and deployment of the application.

The newspaper cutting software was developed separately by another
developer. I did not develop that software. My application consumed
and integrated its generated page images, news fragments, thumbnails,
and XML metadata.

## How the System Worked

1. Newspaper pages were designed in Adobe Illustrator.
2. Final page artwork was prepared for print production.
3. Page images were exported for the online edition.
4. A separate cutting application generated individual news image
   fragments, thumbnails, and XML metadata.
5. The PHP e-paper application read the XML metadata.
6. It created clickable hotspot areas over the corresponding page
   images.
7. Readers could select a news area to view the associated news image.
8. For multi-fragment stories, navigation allowed readers to move
   between the available image fragments.

## Live Platform Status

The original Daily Sangbad Konika E-Paper platform remains accessible
online in its legacy form, although it has not been actively updated.

Its core reading functionality is still available:

- Readers can select archived newspaper editions by date.
- Newspaper pages can be browsed in the online reader.
- Individual news items can be opened through clickable image-based
  areas on the newspaper pages.
- News items open in an iframe-based popup overlay.
- The popup provides Next navigation for stories consisting of
  multiple image fragments.

The Next navigation functionality has been confirmed on the live
website. Other controls and historical behaviours have not been
independently re-verified.

This repository presents the historical PHP application and its
architecture as a portfolio project. It is not a claim that the
legacy application is actively maintained or ready for a fresh
production deployment.
